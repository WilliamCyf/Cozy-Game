# 🏝️ Cozy Cove

**A cozy, relaxing island game for the whole family — made for iPhone, up to 4 players at once.**

Fish off the old pier, grow carrots and pumpkins, shake coconuts out of palm trees, cook at the
campfire, pet Mochi the island cat, and work *together* to fix up the island: mend the broken
bridge to Turtle Islet, light the crystal lighthouse, and finally throw a **Lantern Festival** with
fireworks every night.

Everything anyone finds goes into **one shared family basket**, and coins go into **one family jar** —
so nobody competes, everybody helps.

---

## 1. Put the game online (one time, ~5 minutes)

The finished game lives in the **`docs/`** folder. It just needs a free web host.
Pick **one** option:

### Option A — GitHub Pages (free; the repository must be public)
1. On GitHub, open this repository → **Settings** → **General** → scroll to the bottom →
   **Change visibility** → **Public**.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment** choose **Deploy from a branch**.
4. Branch: **`claude/serene-gates-rdurpz`** (or `main` after you merge), folder: **`/docs`** → **Save**.
5. After a minute your game is at **https://williamcyf.github.io/Cozy-Game/**

### Option B — Netlify (free; keeps the repository private)
1. Go to **https://app.netlify.com** and sign up with your GitHub account.
2. **Add new site** → **Import an existing project** → **GitHub** → pick **Cozy-Game**.
3. Branch: **`claude/serene-gates-rdurpz`**, Build command: *(leave empty)*, Publish directory: **`docs`** → **Deploy**.
4. Netlify gives you a link like `https://something.netlify.app` (you can rename it in *Site settings*).

> Both options update automatically whenever new code is pushed to that branch.

## 2. Add it to each iPhone's Home Screen

1. Open your game link in **Safari** on the iPhone.
2. Tap the **Share** button (square with an arrow ⬆︎) → **Add to Home Screen** → **Add**.
3. Open **Cozy Cove** from the Home Screen. It runs full-screen like a real app and works offline.

## 3. Play together (up to 4 players)

1. One person (the **host**) taps **🏝️ Play on our island**. The island is saved on *this* phone,
   so it's best if the same person hosts each time.
2. On the host's phone: menu **☰** → **Family & Invite** shows the island code, e.g. **CRAB 273**.
3. Everyone else taps **🤝 Join family** and types that code.
4. Being on the **same Wi‑Fi** works best. (Some mobile networks block direct phone-to-phone
   connections; if a phone on mobile data can't join, switch it to Wi‑Fi.)

## 4. How to play (also in the game under ☰ → How to Play)

| | |
|---|---|
| 👆 **Walk** | Put your thumb anywhere on the island and slide. Push further to run. Pinch to zoom. |
| 🔘 **Big button** | Changes with what's near you: pick up, shake trees, plant, water, harvest, shop, sell, cook… |
| 🎣 **Fish** | Face the water, **hold** the button, let go to cast. When the bobber dips — **tap!** Then **hold** to reel and **let go** when the fish splashes, so the line doesn't snap. |
| 🌱 **Garden** | Plant seeds next to the cottage, water them, harvest when they sparkle. Rain waters them for you. |
| 📋 **Family Board** | Shared goals that open new places and new fish. |
| ✉️ **Every day** | A letter with a gift in the mailbox, buried treasure on Turtle Islet, and a new request from Captain Shelly at the shop. |
| 📖 **Fish Journal** | 27 kinds of fish to discover — some only at night, at sunset, in the rain, or in special places. |
| 🏅 **Sticker Book** | 22 family awards to collect together (Journal → Stickers). |
| 🧺 **Picnic** | Sit together on the picnic blanket (2+ people) for a small daily bonus. |
| 🏝️ **Island name** | The host can name your island in ☰ → Family & Invite. |

## 5. Cool phone, happy battery

The game was built to stay cool:
* It draws **30 pictures per second** (half the usual work) and never more pixels than needed.
* If the phone gets busy or warm, it **automatically lowers the detail** to stay smooth.
* It slows down further when nobody is touching the screen, and **stops completely** in the background.
* Shadows and lighting are "painted" once when the game starts instead of being calculated every frame.

You can choose in **☰ → Settings → Graphics**: *Cool & cozy* (default), *Extra smooth (60 fps)*, or
*Battery saver*. No sound? Check the silent switch on the side of the iPhone.

## For the curious: how it works

* **3D graphics:** [three.js](https://threejs.org) with hand-written, very light shaders. The whole
  island (terrain, palm trees, cottage, docks, coral…) is generated by code at start-up — there are
  almost no image files, so the app is small and loads fast.
* **Multiplayer without a game server:** the phones talk **directly** to each other (WebRTC). To find
  each other they briefly use two free "matchmakers" at the same time — PeerJS and Trystero (Nostr
  relays) — and whichever answers first wins, so if one is down the other still works.
* **One shared ledger:** the host phone keeps the official record of the island. Every change
  (e.g. "+1 sardine in the basket") is a small entry the host sends to everyone, and every phone applies
  the same entries in the same order — like a family accounting journal — so all copies always match.
* **Home-screen app:** a web manifest + service worker make it installable and playable offline.
* **Sound:** all music and sound effects are synthesized live (Web Audio) — no audio files.

### Developer notes

```bash
npm install            # once
npm run build          # builds src/ -> docs/
npm run serve          # http://localhost:8080
npm run dev            # rebuild automatically while editing
```

Useful URL flags while testing: `?autostart=host&name=Mom&notut&debug&fps&perf`.

Tests (Playwright, using local stand-ins for the matchmakers):

```bash
node tests/play.mjs flow     # whole-game playthrough
node tests/mp.mjs both       # 4 players + a 5th who is turned away
node tests/reconnect.mjs     # dropped connections and a sleeping host
node tests/touch.mjs         # real touch: joystick, button, pinch
node tests/reach.mjs         # can you walk everywhere you should (and nowhere you shouldn't)?
node tests/perf.mjs          # time per frame in busy places
```

Project layout:

```
src/
  main.js            app start-up, screens, main loop, phone sleep/wake
  render/            renderer (frame cap, auto resolution), camera, shaders, textures, shape builder
  world/             island blueprint, terrain, props (trees, cottage, docks…), walking map
  entities/          characters (1 draw call each), name tags, blob shadows
  game/              rules (host), ledger, session, players, fishing, garden, critters, effects…
  net/               finding each other + talking (PeerJS + Trystero)
  ui/                HUD, panels, screens, fish drawings
  audio/             generative music + sound effects
docs/                the built game (this is what gets hosted)
```
